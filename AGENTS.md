# Machinotheca contributor and agent rules

Read \`CONSTITUTION.md\` and \`MIGRATION.md\` before editing the public repo.

- **Publication boundary first.** Never copy private conversations, venting, personal language, internal context, prompts, secrets, personal information, or nonpublic path/URL references into *any* public file, issue, commit or generated artifact. Do not import nonpublic Git history.
- **Copy most engineering work.** Finished and unfinished research, task queues, working technical state, candidate ideas, failed and superseded experiments, diagnostics, methods, model tests and source attributions are all eligible for publication. Never equate 'not featured on the website' with 'not allowed in the repository'. Remove private language from mixed files rather than excluding the legitimate technical material.
- **Separate repository from showcase.** Publish technical studies in the repository at any honest stage, including provisional or failed work. The **curated** website features only specimens/experiments the owner has chosen to showcase and, when labeled working, must link to real local functioning scenes, the ontology and a guide. Do not fabricate completed work or fake scene buttons.
- **Complete and self-sufficient.** Machinotheca's ontology and replacement GitHub Pages engineering runtime must function without any private repository, the old interactive-demos site or the owner's local machine.
- **Be precise about fidelity.** Manufacturer, physical measurement, derivation, audited secondary source, reconstruction, visual aid and hypothesis are distinct; do not claim factory authenticity from a passing browser test.
- **Respect copyrights.** Check audio, photos, diagrams, documentation excerpts and vendored code individually. Do not represent the project's MIT license as a license for third-party assets.
- **Test before release.** Validate content/provenance, JSON schemas, links, browser behavior and intended Pages base path; inspect generated source maps, snapshots and workflow output for private material.
- **Default Git target:** existing \`main\`; do not create unsolicited branches or PRs. Review all public-facing commit language for professional tone and factual accuracy.
- **No unauthorized public registry changes.** Tarium membership requires the owner's direct instruction and an explicit public registry entry; this repository remains self-sufficient either way.
