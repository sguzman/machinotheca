# Machinotheca gallery

**No local interactive specimens are published yet.** The gallery remains deliberately empty until a real exhibit, its independent technical ontology, links and browser tests have been transferred into this repository.

The authoritative machine-readable exhibit index is [index.json](index.json).

### Exhibition behavior

An accepted exhibit displays a real model of the artifact and supports a reader journey:

**gallery → specimen overview → working interactive scene → selected component/mechanism → ontology → source/model evidence → scene**

The gallery must expose revision and evidence limits, distinguish physical machine state from camera/exploded-view state, and avoid empty placeholders or fictional progress entries. The site should work as a static project page at a nested URL.

The first planned exhibitions are the ETA / Unitas 6497-2, Polaroid SX-70, Game Boy DMG-01 and IBM Selectric 721, currently accessible at their original public showcase. They will appear in this index **only after** their own Machinotheca implementations pass the [migration acceptance checks](../MIGRATION.md).
